# 杨林生活网 (iyanglin.com) 已知限制与系统边界手册

## 1. 当前版本业务边界与容量限制

1. **并发承载能力**：
   - 当前单机架构（4核 8G + Docker PostgreSQL）设计最佳并发服务能力在 **300 ～ 500 QPS** 区间，满足杨林本地及周边 20 万常住人口日常峰值访问需求；
   - 若未来出现全县级突发爆款同城活动，建议前置引入 Redis 缓存与 CDN 动静分离。
2. **多媒体存储限制**：
   - 目前用户上传的照片与附件默认保存在服务器本地磁盘持久化目录；
   - 单张图片最大上传限制为 10MB，上传时由前端自动进行质量无损压缩。

---

## 2. 暂缓开放功能清单 (Deferred Features)

为了保障系统架构稳定、规避合规政策风险与高昂运维成本，以下功能在当前正式版中保持锁定或延期发布：
- ⏸️ **实时音视频面试通话**：暂未引入 WebRTC 实时流媒体服务器，当前招聘 ATS 采用“生成企业 HR 微信/手机号并预约线下到场面试”的高效务实模式；
- ⏸️ **跨省外地自动分站系统**：本平台聚焦“云南嵩明·杨林经开区与大学城”，不扩展全国级子域名分站；
- ⏸️ **无人机配送与即时配送调度**：当前本地服务采用“师傅上门预约接单”模式，不接入高成本的外卖骑士即时运力系统。

---

## 3. 技术债务与后续演进建议 (P9 展望)

1. **分布式缓存引入**：
   - 待全站日活跃用户 (DAU) 突破 10,000 时，建议将 Session 与高频配置抽离至 Redis 集群；
2. **读写分离与只读副本**：
   - 当历史发布信息积累超过 100 万条时，可将全站搜索与历史归档查询路由至 PostgreSQL 只读副本；
3. **CDN 深度加速**：
   - 将 `/_next/static/` 静态前端资源无缝接入腾讯云 CDN 节点。
