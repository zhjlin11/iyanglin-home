# 杨林生活网 (iyanglin.com) 业务状态机设计手册

## 1. 状态机总则与流转原则

状态机是系统保持“数据一致性、流程严密性、资金安全性”的基石。杨林生活网全站遵循以下规范：
1. **单一输入源原则**：状态变更只能通过受信任的服务端业务事件驱动，不可跨状态随意跳转；
2. **幂等性防护**：重复触发相同事件时，保持最终状态不变，不重复扣费、不重复履约；
3. **不可逆交易**：一旦进入终态 (`COMPLETED`, `REFUNDED`, `CLOSED`)，绝对不可回滚到活动态。

## 2. 六大核心业务状态机模型

### (1) 商业订单状态机 (`BillingOrder.status`)

```mermaid
stateDiagram-v2
    [*] --> PENDING_PAYMENT : 用户点击结算生成订单
    PENDING_PAYMENT --> PAID : 微信支付回调成功
    PENDING_PAYMENT --> CANCELLED : 用户手动取消
    PENDING_PAYMENT --> CLOSED : 15分钟超时未支付自动关单
    PAID --> REFUNDING : 触发售后退款流程
    PAID --> COMPLETED : 权益充值成功/服务履约完毕
    REFUNDING --> REFUNDED : 原路退款成功到账
    REFUNDED --> [*]
    CANCELLED --> [*]
    CLOSED --> [*]
    COMPLETED --> [*]
```

### (2) 履约服务订单状态机 (`ServiceOrder.status`)

```mermaid
stateDiagram-v2
    [*] --> PENDING_PAY : 提交服务预约
    PENDING_PAY --> PAID : 支付成功 (生成核销码)
    PAID --> ASSIGNED : 平台/商户指派师傅
    ASSIGNED --> SERVICING : 师傅已上门并核验券码
    SERVICING --> COMPLETED : 客户确认完成/自动结单
    PAID --> REFUNDING : 未上门前客户发起申请退款
    REFUNDING --> REFUNDED : 商户同意退款，原路回退
    COMPLETED --> REVIEWED : 客户评价完毕
    REVIEWED --> [*]
    REFUNDED --> [*]
```

### (3) 内容发布与多级审核状态机 (`ContentStatus`)

```mermaid
stateDiagram-v2
    [*] --> PENDING : 用户提交发布 (招聘/房产/二手)
    PENDING --> AI_PASSED : AI 内容风控初筛通过

    AI_PASSED --> APPROVED : 自动上架对外公开
    MANUAL_REVIEW --> APPROVED : 管理员审核通过
    MANUAL_REVIEW --> REJECTED : 违规驳回并通知用户
    APPROVED --> EXPIRED : 到期自然下架
    APPROVED --> TAKEN_DOWN : 遭举报查实紧急下架
    REJECTED --> [*]
    EXPIRED --> [*]
    TAKEN_DOWN --> [*]
```

### (4) 会员 VIP 权益生命周期状态机

```mermaid
stateDiagram-v2
    [*] --> INACTIVE : 注册默认普通身份
    INACTIVE --> ACTIVE : 购买月卡/季卡/年卡支付成功
    ACTIVE --> EXPIRING_SOON : 距到期 <= 3 天触发续费推送
    EXPIRING_SOON --> ACTIVE : 用户续费成功
    EXPIRING_SOON --> EXPIRED : 权益到期自动降级
    EXPIRED --> ACTIVE : 重新充值激活
```

### (5) 招聘 ATS 候选人应聘流转状态机

stateDiagram-v2

## 3. 状态异常自愈与防御机制

1. **分布式并发锁**：状态更新使用乐观锁版本控制或基于数据库事务 (`prisma.$transaction`)，杜绝双发并发调用；
2. **定时对账巡检**：
   - 订单关闭定时器：每分钟扫描 `status = PENDING_PAYMENT` 且 `createdAt < NOW() - 15 MIN`，自动安全流转为 `CLOSED`；
   - 置顶过期定时器：每小时扫描 `pinnedUntil < NOW()`，自动撤除置顶标牌。
