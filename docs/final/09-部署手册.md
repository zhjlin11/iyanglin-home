## 3. 标准一键部署流程

在本地项目根目录下完成代码验证后，发布至远程服务器的标准化命令：

```bash
# 1. 本地完成 TypeScript 类型检查与生产编译
npm run build

# 2. 将代码与依赖打包（排除冗余的大文件）
tar -czf final_deploy.tar.gz .next public package.json prisma src docs

# 3. 通过安全协议传输到生产主机
scp -i ~/.ssh/id_antigravity final_deploy.tar.gz ubuntu@134.175.230.107:/var/www/iyanglin.com/

# 4. SSH 登录主机并执行安全热重载
ssh -i ~/.ssh/id_antigravity ubuntu@134.175.230.107 << 'EOF'
  cd /var/www/iyanglin.com
  tar -xzf final_deploy.tar.gz
  pm2 restart yanglinol-newsite --update-env
  rm final_deploy.tar.gz
  curl -I http://127.0.0.1:3006/api/healthz
EOF
```

## 4. Nginx 反向代理配置参考

文件路径：`/etc/nginx/sites-available/iyanglin.com`

```nginx
server {
    listen 80;
    server_name iyanglin.com www.iyanglin.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name iyanglin.com www.iyanglin.com;

    ssl_certificate /etc/letsencrypt/live/iyanglin.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/iyanglin.com/privkey.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 开启高效静态资源缓存
    location /_next/static/ {
        alias /var/www/iyanglin.com/.next/static/;
        expires 365d;
        access_log off;
    }

    location / {
        proxy_pass http://127.0.0.1:3006;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## 5. 故障快速回滚机制

每次发布上线前，生产服务器保留上一版本的压缩备份：
```bash
# 紧急回滚执行：
cd /var/www/iyanglin.com
tar -xzf .backup/previous_stable_build.tar.gz
pm2 restart yanglinol-newsite
```
服务可在 10 秒内完整恢复至上线前的上一个稳定版本。
