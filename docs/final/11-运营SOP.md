# 杨林生活网 (iyanglin.com) 平台运营操作规范手册 (SOP)

## 1. 运营岗位与责任划分

| 角色岗位 | 负责工作模块 | 核心工作目标 |
| :--- | :--- | :--- |
| **内容审核专员** | 招聘、房源、二手、相亲、社区论坛审核 | 严守内容安全红线，保持审核队列 30 分钟内清零 |
| **商家拓展 (BD)** | 园区企业入驻、本地商家开通好店、师傅上门接单 | 提高杨林经开区真实企业与大学城周边商户活跃度 |
| **商业营销运营** | 置顶推广配置、平台优惠券发行、VIP会员权益活动 | 提升商业变现收入，促进老用户复购与分享转化 |
| **系统管理员** | 平台风控大盘巡检、异常交易核实、系统设置调优 | 保障平台全天候稳定运行，防范恶意刷单与舆情风险 |

## 2. 每日运营例行巡检清单 (Daily Routine)

```
每日巡检时间表
├── 09:00 [早间首巡]
│   ├── 检查后台「待审核队列」，清理昨夜积压的内容发布与认证申请；
│   ├── 查看「异常支付与掉单预警」，核对昨日微信商户号入账金额；
│   └── 检查系统探针健康度（CPU、内存使用率、PM2进程状态）。
├── 14:00 [午间运营]
│   ├── 刷新首页热门招聘置顶与推荐房源位，提升优质商户曝光；
│   ├── 处理用户违规举报工单（涉嫌兼职刷单、虚假房源等）；
│   └── 审核入驻商户提交的营销活动与优惠券。
└── 20:00 [晚间收官]
    ├── 查看全天核心运营 KPI（新增用户、发布量、线索数、GMV）；
    ├── 抽检相亲交友资料真伪，下架恶意广告帖；
    └── 检查每日数据自动备份任务状态。
```

## 3. 本地特色类目运营要点

### (1) 嵩明杨林经济技术开发区招聘运营
- **重点企业对接**：主动为园区重点规上企业（装备制造、食品医药、智能物流）开通绿色发布认证通道；
- **真实性承诺**：严厉打击“日结刷单”、“兼职打字”等虚假招聘信息，一经查实立即封停账号并拉黑企业主体。

### (2) 杨林大学城学生生活与兼职
- **校园合规**：围绕云南工商学院、云师大商学院、滇池学院等高校学生需求，设立勤工俭学专区与毕业季二手教材/数码转让专区；
- **防诈骗关怀**：在相关求职与租房详情页顶部常态化悬挂“谨防电信网络诈骗”温馨提示标牌。

### (3) 同城相亲与严肃交友
- **实名保密**：交友嘉宾照片默认实施适度隐私遮罩，联系方式必须经过双方意愿确认或平台正规核销后方可展示，保护用户隐私。
