# 杨林生活网 (iyanglin.com) 客户服务标准操作手册 (SOP)

## 1. 服务标准与时效承诺

- **首问响应时效**：客服工单在 3 分钟内完成首次人工接单响应；
- **一般咨询处理**：15 分钟内答复并办结；
- **交易纠纷与退款投诉**：24 小时内完成调查核实并给出解决方案；
- **服务态度红线**：禁止推诿扯皮、禁止透露用户个人隐私、禁止使用侮辱性语言。

## 2. 常见问题标准答复话术 (Q&A)

### Q1: “我在网站付了 5 元置顶招聘，为什么列表中没有排在第一位？”
- **标准答复**：
  > “您好！感谢您支持杨林生活网。置顶信息展示规则为：同一类目下若有多位用户同时购买置顶，系统将按照【最新付费置顶时间】或【置顶套餐等级】排序轮播展示。建议您可在置顶有效期内通过个人中心使用‘一键刷新’功能提升排名。如需协助，我可帮您查询该岗位的具体排期。”

### Q2: “我预约的家政保洁师傅迟到了/没按时上门，我要退款！”
- **标准答复**：
  > “非常抱歉给您带来了不便！为了保障您的权益，由于该订单尚未核销消费，您可以在【个人中心 - 我的订单】中直接点击【申请全额退款】，系统将在核实后原路退回至您的微信支付账户。同时，我们将对该服务商进行履约扣分处置。”

### Q3: “我的账号为什么被封禁了？怎么解封？”
- **标准答复**：
  > “您好，系统检测到您的账号可能存在频繁发布外部引流广告或涉及不合规内容的行为，触发了平台安全风控机制。若您属于误操作或被他人盗号，请提供您注册时使用的手机号及身份证件正面照片发送至客服邮箱申诉，我们将在 1 个工作日内人工复核。”

## 3. 客户纠纷与争议升级流转机制

```
纠纷处理三级流转
├── 一级处理 (在线客服专员)
│   ├── 倾听诉求，核对用户账号、订单号及交易截图；
│   └── 属于平台责任且金额 <= 50 元，可直接发起退款或补偿 100 平台积分。
├── 二级升级 (运营主管)
│   ├── 涉及买卖双方互撕、虚假房源扣押押金、师傅施工质量瑕疵；
│   └── 冻结服务订单款项，要求商家提供上门履约照片，组织线上调解。
└── 三级升级 (合规与法务)
    ├── 涉及重大诈骗线索、人身安全威胁、严重违禁品交易；
    └── 立即保留全部数据库日志、IP及操作证据，协助用户向杨林派出所报案。
```
