# 01 - 杨林生活网（iyanglin.com）系统架构说明书

## 1. 架构总览与演进目标

杨林生活网（`iyanglin.com`）定位于立足云南省昆明市嵩明县杨林经济技术开发区与杨林职教园区的综合性本地数字化生活服务与商业中台。
经历 P0 至 P8 的全周期研发，系统确立了 **“微内核 + 业务中台 + 多端接入 + 开放数字底座”** 的现代化应用架构。

## 3. 多组织多租户物理与逻辑强隔离机制

1. **组织实体模型 (`Organization`)**：
   - 统一承载 `ENTERPRISE`（招工/企业）与 `MERCHANT`（商户/服务师傅）；
   - 通过 `ownerId`、`members`、`roles`（`OWNER`, `ADMIN`, `OPERATOR`, `HR`, `CUSTOMER_SERVICE`, `FINANCE`, `TECHNICIAN`）严格限制组织内部成员访问范围。
2. **403 铁壁鉴权原则**：
   - 服务端所有企业数据接口（ATS 简历库、CRM 客户、订单履约、私有知识库、待办任务）强制校验当前上下文中登录者与目标资源的 `organizationId`；
   - 严禁信任前端传入的所属机构参数，跨租户越权访问统一由网关与服务层抛出 `HTTP 403 Forbidden`。

## 4. 业务事件总线（Event Bus）设计

- **不可篡改性（Append-Only）**：`BusinessEvent` 模型严格只做追加插入，杜绝物理篡改与物理删除；
- **重试与死信（DLQ）**：内置最大重试 3 次退避，超过阈值自动落入死信队列并记录告警日志；
- **防死循环（Depth Limit）**：任何由事件驱动的工作流均注入链路跟踪 `executionId`，递归调用深度严格限制在 `depthLimit <= 3` 以内。
