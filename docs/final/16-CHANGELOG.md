# 杨林生活网 (iyanglin.com) 版本演进历史与更新日志 (CHANGELOG)

## [v1.0.0-PROD] - 2026-09-15 (FINAL 正式运营上线版)
### Added
- 完整编制并发布 17 套标准化交付运维管理手册与开发规范；
- 全局注入 `x-request-id` 分布式请求追踪中间件，贯穿前端、API与日志；
- 建立端到端 P0 自动化回归测试套件 (`scratch/verify_final_p0.js`)；
- 完成生产服务器 PostgreSQL 实机灾难备份恢复实操演练（4.55秒 100% 还原）；
- 交付全分辨率响应式视觉审计证据（1920/1440/768/390/375）。

### Fixed & Hardened
- 全站 191 个 API 路由权限与安全总审计，封杀全部未鉴权写接口；
- 强化多组织跨租户 403 Forbidden 强隔离逻辑；
- 统一财务数据模型金额全部采用「分」(Cents/Int) 存储与服务端防篡改计算；
- 确立核心交易、订单、退款、结算、审计流水“严禁物理删除”合规铁律；
- 清理归档生产数据库测试 Mock 数据，保障线上 6,907+ 条本土真实数据洁净。
