# 2026-07-25 订单详情与内容筛选开发记录

## 本次完成

- 内容管理页增加“内容类型”筛选：
  - 全部类型
  - 文章
  - 招聘
  - 分类信息
- 内容管理页删除提示增强：
  - 删除内容时会提示“关联订单会保留”
  - 删除成功后会显示关联订单保留数量
- 内容删除接口增强：
  - 删除内容前统计关联订单数量
  - 删除内容后返回 `relatedOrders`
  - 订单不会因为内容删除而删除
- 订单接口增强：
  - 支持通过 `id` 获取单个订单详情
- 新增订单详情页：
  - `/admin/orders/[id]`
  - 展示订单号、状态、内容类型、金额、创建时间
  - 展示套餐快照
  - 展示关联内容标题和内容 ID
  - 展示订单相关操作记录
- 订单列表页新增“详情”入口。

## 权限和业务规则

- 付费/未付费不限制管理员内容管理。
- 管理员删除内容时，订单作为收费记录继续保留。
- 删除内容不会删除历史订单。

## 浏览器验证路径

1. 打开 `/admin/content`。
2. 确认“内容类型”筛选存在并可选择“分类信息”。
3. 创建一条带订单关联的测试内容。
4. 在内容管理页搜索该内容。
5. 点击删除并确认。
6. 确认删除成功提示包含“关联订单已保留”。
7. 打开 `/admin/orders/[id]`。
8. 确认订单详情页展示订单信息、套餐快照和关联内容信息。
9. 清理测试订单和套餐。
